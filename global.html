(async) capture(fpOut, opt) → {Promise}

Description:

  • 以瀏覽器擷取網頁操作時所發出之請求

    依序執行opt.steps，每步為一個階段(S1_<名稱>、S2_<名稱>…)，期間完成之請求記入該階段；步驟失敗時印出訊息並繼續後續步驟，失敗之階段記於failedSteps； 只記錄opt.origins內之來源，其中XHR與fetch視為服務之請求逐筆記錄，其餘(網頁、腳本、樣式、圖片等)只計數

    內網或無法下載playwright瀏覽器時，以opt.browserChannel使用本機已安裝之Chrome('chrome')或Edge('msedge')，或以opt.executablePath指定瀏覽器

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔k6.exe: 首次使用時自k6官方發布(版本標籤之資產網址，zip)下載(或自鏡像取得)並解出，以bin/manifest.json之SHA-256與大小校驗，之後自快取取得(亦校驗)

    規格: 外部執行檔之存放下載校驗與離線(制式規格)§6；實作為wsemi之fsEnsureBins，本套件不另寫下載、快取、鏡像、校驗與解壓。 本套件為主幹模式：執行時先取GitHub主幹之bin/manifest.json(最新清單)，取不到時用npm包內之基準清單。 環境變數：W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE，見README〈外部執行檔〉

Source:
  • ensureBins.mjs, line 36
Example
import ensureBins from 'w-scan-stress/src/ensureBins.mjs'

async function test() {

    //部署前預先取得(連網機器設W_BIN_CACHE=<資料夾>後執行，該資料夾即可作為離線鏡像W_BIN_MIRROR)
    let bins = await ensureBins()

    console.log('bins', bins)
    // bins { 'k6.exe': 'D:\\xxx\\node_modules\\w-scan-stress\\bin-cache\\<sha256>\\k6.exe' }
}
test()
    .catch((err) => {
        console.log('catch', err)
    })
